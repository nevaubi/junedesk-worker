# Rules for this folder
- Files too large or unusual for the edge runtime go to the Render worker (`render-worker/`) through `/api/public/worker/*`, authorized by `JUNEDESK_WORKER_KEY` and limited to jobs leased to the worker; it uses per-job signed links and never holds storage keys. Why: heavy conversion (Docling, LibreOffice, ffmpeg, archives) without exposing credentials.
- Background work when nobody has the app open runs from the Render worker's clock: every ~4 minutes it calls `/api/public/worker/tick` once per step (`BACKSTOP_STEPS` in `src/lib/jobs/backstop.server.ts`), each step its own request with its own time budget; the managed 5-minute schedule only runs the database `sweep` step. Why: the scheduler hangs up after 5 s and the platform cancels the run, and one step per request keeps memory bounded.
- Render deploys the worker from the separate GitHub repo `nevaubi/junedesk-worker` (copy of `render-worker/`); push changes there after editing the folder. Why: Render cannot read the Lovable repo.
